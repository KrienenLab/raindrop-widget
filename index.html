Krienen Lab · Data viewers (demo page)

A stand-in for a page of the lab website. The viewer below is an ordinary iframe, so it works the same way inside any site builder that allows embedded HTML.

Embedding it

<iframe src="https://krienenlab.github.io/raindrop-widget/widget.html"
        style="width:100%; height:90vh; border:0" allowfullscreen loading="lazy"></iframe>

The Mouse | Marmoset buttons switch datasets; widget.html#marmoset opens on the marmoset.

Below it the page goes on as usual: a plain scroll over the widget scrolls the page.
